# sih-india-airfare-price-index
Real-time Airfare Price Index for India using automated web scraping, data normalization, statistical price indexing, and CPI-aligned analysis.

## Backend API module (`api/`)

FastAPI backend that exposes the Index Engine and related modules to the frontend dashboard, with stub implementations swappable for the real engines. See [`api/README.md`](api/README.md) for setup, endpoints, and authentication.
